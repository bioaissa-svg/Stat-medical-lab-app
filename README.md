# 🔬 المنصة التعليمية للتحليل المخبري وتوليد التقارير الطبية

تطبيق Streamlit يقوم بـ:
1. **تنظيف تلقائي** لملفات نتائج التحاليل (xlsx/csv) — يكتشف رأس الجدول
   الحقيقي حتى لو سبقته صفوف عناوين، ويدمج الأعمدة "المتبادلة" (مثل
   `P.hivernale` / `P.estivale`) في عمود فئوي واحد تلقائياً.
2. **تحليل إحصائي عام**: مقارنة أي متغير رقمي بين فئتين (مثلاً فترة شتوية
   مقابل فترة صيفية)، مع اختيار تلقائي بين t-test و Mann-Whitney U حسب نتيجة
   اختبار التوزيع الطبيعي، وحساب حجم الأثر (Cohen's d أو r).
3. **تحليل حسب فئة فرعية إضافية** (مثل الجنس) لكشف تفاعلات محتملة.
4. **رسوم بيانية تفاعلية** (Plotly) داخل الواجهة.
5. **توليد تقرير PDF** كامل بالعربية يترجم النتائج الإحصائية إلى نص مقروء،
   شامل الجداول والرسوم البيانية.

## 📁 بنية المشروع

```
app.py                      # الواجهة الرئيسية (Streamlit)
requirements.txt            # المكتبات المطلوبة
utils/
  data_processing.py        # تنظيف الملفات تلقائياً
  stats_engine.py           # محرك الاختبارات الإحصائية
  charts.py                 # الرسوم البيانية (Plotly + Matplotlib)
  report_pdf.py             # توليد تقرير PDF بالعربية
assets/
  FreeSerif.ttf              # خط يدعم العربية والفرنسية (لتقرير PDF)
  FreeSerifBold.ttf
```

## 🚀 التشغيل محلياً

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ☁️ النشر على Streamlit Community Cloud

1. انسخ كل الملفات أعلاه إلى مستودعك على GitHub (حافظ على نفس بنية
   المجلدات، خصوصاً `utils/` و `assets/`).
2. من [share.streamlit.io](https://share.streamlit.io)، اربط المستودع
   واختر `app.py` كملف رئيسي.
3. لا حاجة لأي إعداد إضافي — `requirements.txt` كافٍ لتثبيت كل شيء تلقائياً.

## 📝 ملاحظة تقنية حول دعم العربية في PDF

التقرير يستخدم مكتبة `reportlab`، التي تدعم تلقائياً تشكيل الحروف العربية
واتجاه RTL داخل كائنات `Paragraph` عند استخدام خط TrueType يحتوي حروفاً
عربية (هنا: `FreeSerif.ttf`، مرفق في `assets/`). **لا حاجة** لمكتبات إضافية
مثل `arabic_reshaper` أو `python-bidi` — تم اختبار هذا فعلياً ويعمل بشكل
صحيح.

## 🔧 التخصيص

- لإضافة شعار المخبر في التقرير: مرر `logo_path="assets/logo.png"` إلى
  `build_report()` في `app.py`.
- لإضافة مجالات مرجعية (Reference ranges) وتنبيهات القيم الشاذة: يمكن
  توسيع `stats_engine.py` بدالة `flag_abnormal_values(df, ranges_dict)`.
- المحرك الإحصائي عام تماماً: يعمل مع أي عمود فئوي (بفئتين) وأي أعمدة رقمية،
  وليس فقط "الموسم" — يمكن استخدامه أيضاً لمقارنة `sex` أو أي متغير آخر.

## ⚠️ حدود حالية (لتطوير مستقبلي محتمل)

- المقارنة الحالية بين **فئتين فقط**. لمقارنة أكثر من فئتين (مثلاً أكثر من
  موسمين) يلزم إضافة ANOVA / Kruskal-Wallis.
- لا يوجد حالياً استخلاص تلقائي لمجالات الرجوع (Reference intervals) وفق
  منهجية CLSI رغم ذكرها في وصف التطبيق — يمكن إضافتها كوحدة منفصلة
  `utils/reference_intervals.py` باستخدام طريقة النسب المئوية غير المعلمية
  (percentile method) الموصى بها في CLSI C28-A3.
